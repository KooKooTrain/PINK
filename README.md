## About

PINK is an awareness project focused on feminism. The website shares information and resources and gives people a place to start the conversation.

## My role

Co-founder & Web developer. I built the site and handle its design, layout and responsiveness.

## Stack

HTML, Tailwind CSS, JavaScript. Hosted on Netlify.

## Run locally

```bash
git clone https://github.com/YOUR_USERNAME/pink.git
cd pink
```

Open `index.html` in your browser.
